# موقع ولوحة تحكم مجلس الجمعيات الأهلية بمنطقة عسير

نموذج أولي (Prototype) لموقع المجلس العام ولوحة تحكم فريق المجلس، في ملف HTML واحد يعمل دون خادم.
**للفريق فقط — لا يُنشر.**

## المحتوى

| المسار | الوصف |
|---|---|
| `src/site.src.html` | مصدر الموقع واللوحة (HTML + CSS + JS) مع عناصر نائبة `{{…}}` تُملأ عند البناء |
| `src/assets/` | الشعار، صور مجلس الإدارة (مقصوصة الخلفية)، شعار جمعية ابتسامة، الخلفيات |
| `data/public.json` | الحقول العامة للجمعيات (539 جمعية) |
| `data/internal.redacted.json` | سجلات اللوحة **بعد حذف البيانات الشخصية** (البريد، الجوال، الرئيس، المفوض، الرقم الموحد) |
| `data/geo.json` | حدود المحافظات الـ19 والمناطق المجاورة (مُسقطة، بلا فراغات) وأيقونات المحافظات |
| `data/suplogos.json` · `data/logos/` | الشعارات الرسمية للجهات الإشرافية (SVG/WebP) |
| `tools/` | سكربتات تجهيز البيانات والخرائط |
| `tests/` | اختبارات Playwright للموقع واللوحة |

## البناء

```bash
python3 build.py          # يُنتج dist/asir-council-site.html
```

- إن وُجد `data/internal.json` (ملف المجلس الحقيقي) يُستخدم في البناء، وإلا تُستخدم النسخة المنقّحة.
- `data/internal.json` وملفات Excel الأصلية مستبعدة من المستودع عبر `.gitignore` ولا تُرفع أبداً.

## الاختبارات

```bash
npm i -D playwright && npx playwright install chromium
python3 build.py && node tests/t25.js
```

## ضوابط البيانات

- الموقع العام يعرض الحقول العامة فقط؛ بيانات التواصل تظهر فقط للجمعيات الموافقة.
- البيانات الشخصية في اللوحة مخفية افتراضياً، وكل إظهار لها يُسجَّل.
- التقارير والتنزيلات من اللوحة لا تتضمن بيانات التواصل الشخصية.
- استخدام شعارات الجهات يخضع لضوابط الجهات المالكة، ولا يعني شراكة أو اعتماداً.
- حدود البرك والأمواه والفرشة مشتقة تقريبياً حتى اعتماد الطبقة الرسمية.

## أبرز الوحدات

**الموقع:** الرئيسية بالخريطة التفاعلية، دليل الجمعيات (خريطة/محافظات/بطاقات/جدول/إحصاءات) بفلاتر المحافظة والجهة الإشرافية والمجال، صفحة الجمعية، الاستشارات والحجز، المجتمعات المهنية (محور)، عن المجلس والحوكمة، المركز الإعلامي، النمط الداكن ونمط الجهاز.

**اللوحة:** الجمعيات (الدليل، حسب الجهة الإشرافية، حسب المحافظة، التراخيص، طلبات التحديث، الجودة، التحليلات، القرارات)، التقارير (Excel منسّق وPDF)، الاستشارات، الشراكات والمشاريع، المجتمعات ومحور، المحتوى، الحوكمة، الإعدادات والتطبيقات، ومركز الإطلاق المؤقت.
